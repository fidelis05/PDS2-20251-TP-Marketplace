\item Como usuário, quero fazer login com meu e-\/mail e senha, para acessar minha conta com segurança.
\item Como usuário, quero visualizar a lista de produtos à venda e aplicar filtros (nome, categoria, preço), para encontrar o que desejo com facilidade.
\item Como usuário, quero acessar os detalhes de um produto, para ver sua descrição completa e informações do vendedor.
\item Como usuário, quero adicionar produtos ao meu carrinho, para realizar uma compra com múltiplos itens.
\item Como usuário, quero remover produtos do meu carrinho, para gerenciar o que será comprado.
\item Como usuário, quero finalizar a compra dos itens do meu carrinho, para concluir o pedido.
\item Como usuário, quero comprar um produto diretamente da página de anúncio, para agilizar o processo de compra.
\item Como usuário, quero cadastrar um novo produto, informando nome, descrição, preço e quantidade, para colocá-\/lo à venda.
\item Como usuário, quero visualizar meus pedidos realizados, para acompanhar o histórico de compras.
\item Como usuário, quero cancelar um pedido ainda não processado, para corrigir enganos ou desistências.
\item Como usuário, quero editar ou excluir meus produtos cadastrados, para manter o controle sobre meus anúncios.
\item Como usuário, quero ver uma confirmação ao realizar ações importantes (como deletar produto ou finalizar pedido), para evitar erros.
